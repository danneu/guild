{# Shared resend-confirmation-email button script. Both /me/edit and /confirm-email render a `.send-verification-email` button next to an empty `.result` span and POST to /api/verify-email. CSRF is origin/referer-based (server/middleware/protect-csrf.ts), so the fetch needs no token -- it only has to be same-origin, which is why `url` defaults to a relative path. Resend is throttled in the database (60s), so a 429 here is expected and means "you already have a fresh link", not a failure. Params let each page keep its own copy: url - endpoint to POST to label - text restored on the button after the cooldown sendingLabel - text shown on the button while the request is in flight successText - shown in `.result` on 2xx throttleText - shown in `.result` on 429 errorText - shown in `.result` on any other failure showStatus - append "Error: " detail and log to the console (the /me/edit flavor) cooldownMs - how long the button stays disabled after a response #} {% macro resendScript( url = '/api/verify-email', label = 'Resend the confirmation email', sendingLabel = 'Sending...', successText = ' Sent. Check your email.', throttleText = ' We just sent one. Please wait a minute before trying again.', errorText = ' Something went wrong. Please try again in a moment.', showStatus = false, cooldownMs = 10000 ) %} {% endmacro %}
